Push instructions for akdamia scaffold

1) Recommended (GH CLI):
   - Install and authenticate: gh auth login
   - From the folder containing 'akdamia' run:
       cd akdamia
       gh repo view treesbeats/akdamia --json exists || gh repo create treesbeats/akdamia --public --source=. --remote=origin
       git add .
       git commit -m "Initial scaffold"
       git push -u origin main

2) If you prefer to use a Personal Access Token (PAT):
   - Create a token with 'repo' scope at https://github.com/settings/tokens
   - Set it temporarily in PowerShell (do NOT store in persistent files):
       $env:GITHUB_TOKEN = 'ghp_xxx'
     then from the parent folder run:
       .\push_to_github.ps1
     After push, unset the token:
       Remove-Item Env:\GITHUB_TOKEN

3) Manual git push (no token):
   cd akdamia
   git init
   git checkout -b main
   git remote add origin https://github.com/treesbeats/akdamia.git
   git add .
   git commit -m "Initial scaffold"
   git push -u origin main
